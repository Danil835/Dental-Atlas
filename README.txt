Атлас стоматолога — обучение и тест по стоматологическим инструментам (RU/UA)

ЗАПУСК
1. Распакуйте папку.
2. Откройте index.html двойным кликом (браузер Chrome, Edge, Safari или Firefox).
   Интернет нужен только для шрифтов (без него сайт работает со стандартными шрифтами).

ЗАГРУЗКА НА ХОСТИНГ
Загрузите index.html и three.min.js в одну папку на любой статичный хостинг
(GitHub Pages, Netlify, Cloudflare Pages, обычный хостинг). Больше ничего не нужно.

ИСХОДНИКИ (папка src)
data1-3.js    тексты инструментов (RU/UA): обзор, инструкция, пример
models1-3.js  3D-модели (Three.js), по функции на каждый инструмент
app.js        интерфейс, обучение, тест
head.html     стили и разметка
build.sh      собирает всё в один index.html (нужен bash)
